# Scoreboard Bridge Artifacts

This directory stores weekly JSON exports generated by `tradectl scoring bridge`.
Each file follows the schema defined in §3.25.1 (`bridge.v1`) and ties Conviction /
realized RR / Spread penalties back to Profit Loop and Execution Bridge evidence.

For Runbook `RUN-GOV-BOARD-01`, the same snapshot can be exported into
`scoreboard/alpha/<week>.json` via the `--out` flag. The alpha tree mirrors the
bridge structure so governance reviews can attach `scoreboard/alpha/*.json` while
profit readiness automation continues to reference the canonical bridge output here.
