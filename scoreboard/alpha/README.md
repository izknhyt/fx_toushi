# Alpha Scoreboard Exports

Weekly snapshots exported via `tradectl scoring bridge --week <YYYY-WW> --out scoreboard/alpha/<YYYY-WW>.json`.
These files mirror the bridge schema (bridge.v1) but live under the `alpha/` tree so
Runbook `RUN-GOV-BOARD-01` can attach them directly alongside `reports/performance/profit_loop_daily.md`
and the Profit Readiness levers.
