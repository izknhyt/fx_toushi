# Onboarding Checklist

Welcome to the ops workflow. Complete each task and keep the checklist updated.

- [ ] Read core runbooks (RUN-OPS-01, RUN-INC-01) and summarize key steps.
- [ ] Verify local tooling setup (config-init, schema-validate, check-runbooks).
- [ ] Run a dry-run CLI flow for ops readiness and capture output notes.
- [ ] Review recent validation playbooks and note ownership.
- [ ] Confirm access to evidence and metrics folders.
