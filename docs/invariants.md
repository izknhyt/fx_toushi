# Invariants

Unchangeable rules every change must preserve. Violations block merge.

## I1. Candidate contract

Every strategy plugin under `src/strategies/` must emit `src.contract.Candidate` objects with **all 14 fields populated**:

| field | type | notes |
| --- | --- | --- |
| `strategy_id` | `str` | Matches the plugin's declared id. |
| `symbol` | `str` | e.g. `"USDJPY"`. |
| `side` | `Literal["long", "short"]` | |
| `entry` | `float` | For `long`: `stop < entry < target`. For `short`: `target < entry < stop`. |
| `stop` | `float` | |
| `target` | `float` | |
| `expected_edge` | `float` | Pre-cost expected R. |
| `estimated_cost` | `float` | ≥ 0. Sourced from `config/execution.yaml` curves — not a constant. |
| `confidence` | `float` | Within `[0.0, 1.0]`. |
| `expected_holding_minutes` | `int` | > 0. |
| `portfolio_group` | `str` | Declared in `config/portfolio.yaml`. |
| `exposure_bucket` | `str` | Declared in `config/portfolio.yaml`. |
| `regime_fit` | `float` | `[-1.0, 1.0]`; the regime layer provides this. |
| `timestamp` | `datetime` | Timezone-aware; matches the bar timestamp that produced the signal. |

Enforced by `tests/contracts/test_candidate_contract.py` — loops over every registered strategy, runs against a canned context, calls `src.contract.validate_candidate` on every emitted candidate.

## I2. Parity (one decision path)

Backtest, shadow, and live must route through `src/decision_path.py`. Mode-specific shortcuts are forbidden.

Enforced by `tests/test_parity.py` — given a fixed seed and a canned input window, the admission decisions produced in backtest, shadow-replay, and dry-live modes must be **byte-identical**.

## I3. Cost positivity

Under every non-zero configuration of `config/execution.yaml`, a round-trip trade must yield `realized_cost > 0`. A backtest that emits zero cost is a bug, not an optimization.

Enforced by `tests/test_cost.py` — enumerates each section of `execution.yaml` and asserts that any non-zero value reaches the simulated PnL.

## Evidence discipline

A file under `reports/` qualifies as evidence only if it meets **all** of:

1. Generated by actual pipeline execution in this repo (not a template, not a human-edited fixture).
2. Carries a sidecar `{filename}.provenance.json` (or in-file metadata block) containing `generator_command`, `commit_hash`, `dataset_hash`.
3. Numeric patterns do not repeat with period ≤ 5 across rolling windows.
4. Bootstrap CI bounds with n < 300 are marked `weak_evidence: true` in the sidecar.

The `evidence-auditor` subagent periodically sweeps `reports/` for violations. Suspect files move to `archive/synthetic/` with a note.

## Escalation

If honoring an invariant blocks a legitimate change:

1. Do **not** bypass the invariant with a workaround or a `# type: ignore`.
2. Open a charter amendment in a separate PR explaining why the invariant needs to weaken or tighten.
3. Once merged, land the originally-blocked change.

The cost of this friction is the cost of the invariants meaning something.
